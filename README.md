# EBus Analyzer

Browser tool that simplifies reverse engineering of eBUS traffic using
[ebusd](https://github.com/john30/ebusd).

- Decodes telegrams with the definitions from
  [ebusd-configuration](https://github.com/john30/ebusd-configuration)
- Highlights unknown telegrams and helps analyse them
- Reads and writes eBUS TypeSpec definitions

Status: requirements phase. See [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md).
